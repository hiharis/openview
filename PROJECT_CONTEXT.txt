1. PROJECT OVERVIEW
OpenView is an open source, fast, clean, and sleek offline file viewer for Android.
- Core Promise: NO ads, NO accounts, NO analytics, NO tracking, and NO internet permission.
- Purpose: Replace ad-ridden, slow document viewers with a stable, lightweight utility prioritizing speed over feature bloat.
- Phase 1 Scope: Fast viewing of TXT, Code files (.py, .kt, .java, .cpp, .js, .html, .css, .json, .xml, .md), PDF (android.graphics.pdf.PdfRenderer), and DOCX (structured readable view). Legacy .doc shows a friendly "not supported yet" screen. System "Open with" intent filter, Recents list via Room, and Settings via DataStore.

- Dependency Management: Gradle Version Catalog (libs.versions.toml)

3. ARCHITECTURE
- MVVM with Unidirectional Data Flow (UI -> Event -> ViewModel -> StateFlow -> Compose UI).
- Layered Separation:
  - UI Layer: Screen composables consuming ViewModel UI state with collectAsStateWithLifecycle.
  - Reusable Components: Modular widgets in ui/components/ (OpenViewTopAppBar, FileCard, SettingsRow, ViewerErrorView).
  - Navigation: Centralized NavGraph with sealed Screen destinations; OpenFileSession state holder avoids string URI route bugs.
  - Data Layer: Room Database for recent files history & scroll positions; DataStore for settings preferences.
  - Core/Router: SAF Uri abstraction, MIME & extension type inference, magic bytes sniffing, and viewer dispatching.
- Modern Accessible Material 3 Design System:
  - Accent Color: Modern Blue (#1D63ED / AccentBlue).
  - Light mode: Soft off-white background (#F8F9FA), pure white cards/surfaces (#FFFFFF), dark gray text (#1E2022).
  - Dark mode: Deep charcoal background (#121418), dark gray cards/surfaces (#1C1F26), off-white text (#F0F2F5).
  - Geometry: Generous rounded corners (16–24dp), 56dp minimum touch targets, subtle card elevation/depth, color-coded format badges (PDF red, Word blue, Text green, Code purple).
  - Material You / dynamic color completely disabled. All color tokens centralized in Color.kt and Theme.kt.
- Strict Constraints: Zero INTERNET permission, zero external tracking dependencies, all UI strings defined in strings.xml, all dimensions in Dimens.kt.

  - TXT Viewer: Size <= 2MB read fully on IO thread, > 2MB background streaming chunks, BOM (UTF-8, UTF-16LE, UTF-16BE) and valid UTF-8 detection with Windows-1252 fallback, word wrap toggle, DataStore font size, pinch-to-zoom scaling, cancellable search with prev/next navigation, empty file card.
  - Code Viewer: Monospace typography, line number gutter with vertical divider, language detection from extension with header chip, regex-based syntax highlighting (keywords, strings, comments, numbers) on demand, horizontal scroll, word wrap toggle, search with prev/next navigation.
  - PDF Viewer: ContentResolver openFileDescriptor and android.graphics.pdf.PdfRenderer with seekable fallback copying to cacheDir, LazyColumn page rendering with LRU bitmap cache, pinch-to-zoom, jump-to-page dialog, floating page indicator pill, password-protected PDF handling.
  - DOCX Viewer: Pure zero-external-dependency parser via ZipInputStream + XmlPullParser on word/document.xml, extracting headings (Heading1..6, Title), paragraphs with bold/italic/underline/strikethrough formatting, bullet lists, and tables (DocxTableCard).
  - Unsupported Screen: Friendly legacy .doc guidance and unsupported file format messaging with string resources.

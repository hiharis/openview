1. PROJECT OVERVIEW
OpenView is an open source, ultra-fast, clean, and sleek document and code reader for Android.
- Core Promise: NO ads, NO accounts, NO analytics, NO tracking, NO background bloat.
- Network Policy: Internet access is strictly restricted to user-initiated and 10-day reminder app update checks from GitHub Releases. The document viewers, parsers, and local file browsing remain 100% offline.
- File Support:
  - Text & Code: Plain text (.txt, .log, .csv, .tsv) with streaming/BOM detection; Syntax-highlighted code (.py, .kt, .java, .cpp, .c, .h, .hpp, .js, .ts, .html, .css, .json, .xml, .md, .sh, .sql).
  - PDF: Native android.graphics.pdf.PdfRenderer with LRU bitmap cache, pinch-to-zoom, jump-to-page, night mode, and fit mode.
  - Word: Pure zero-dependency DOCX parser (ZipInputStream + XmlPullParser) extracting headings, styled text, bullet lists, and tables. Legacy .doc displays an informative conversion guide.
  - Images: JPG, JPEG, PNG, WEBP, BMP via BitmapFactory with inSampleSize downsampling, memory bounds checks, OOM recovery, and pinch/pan zoom (1x to 6x).
- Storage & Discovery:
  - System SAF "Open with" and "Open document" intent filters (content:// and file://).
  - Device Document Discovery: Direct java.io.File scanning of phone's Download and Documents folders for supported formats.
  - Recents history: Local Room database tracking recent files and reading positions.
  - User Settings: Preferences DataStore for theme mode (Light/Dark/System), font size, and update timestamps.

3. ARCHITECTURE
- MVVM with Unidirectional Data Flow (UI -> Event -> ViewModel -> StateFlow -> Compose UI).
- Layered Separation:
  - UI Layer: Screen composables consuming ViewModel UI state via collectAsStateWithLifecycle.
  - Reusable Components: Modular widgets in ui/components/ (OpenViewTopAppBar, FileCard, SettingsRow, ViewerErrorView, DraggableFastScrollBar, PinchZoom, UpdateDialog).
  - Navigation: Centralized NavGraph with type-safe Screen routes; OpenFileSession state holder eliminates URI route encoding/truncation bugs.
  - Data Layer:
    - Room Database: Recent files history, metadata, and timestamps.
    - DataStore Preferences: Theme mode, reading font size, and last update check timestamp.
    - Device Document Scanner: java.io.File scanning of Environment.getExternalStoragePublicDirectory (Download & Documents).
    - Update Manager: GitHub Releases API client, SHA-256 digest verification, and FileProvider installer.
  - Core & Router: ContentResolver SAF abstractions, 5-tier FileRouter format sniffer (extension -> magic bytes -> MIME -> UTF-8 text sniffing -> fallback).
- Modern Accessible Material 3 Design System (4 Built-in Themes):
  - Light: Modern Blue (#1D63ED) on crisp off-white background (#F8F9FA) with pure white surfaces (#FFFFFF).
  - Dark: Charcoal background (#121418) with dark gray surfaces (#1C1F26) and soft blue primary (#6B9DFE).
  - Red & White: Bold Crimson Red (#D32F2F) primary with pure white surfaces (#FFFFFF) and rose container accents (#FFFFEBEE).
  - Forest: Soothing Emerald Green (#10B981) primary on deep pine dark background (#0D1914) with dark spruce surfaces (#15261F).
  - Geometry: Generous rounded corners (16–24dp), 56dp minimum touch targets, subtle card elevation/depth, color-coded format badges (PDF red, Word blue, Text green, Code purple).
  - Material You / dynamic color completely disabled; all color tokens centralized in Color.kt and Theme.kt.
- System Permissions & Security:
  - android.permission.READ_EXTERNAL_STORAGE (maxSdkVersion="29"): For document discovery on Android 8.0–10.
  - android.permission.MANAGE_EXTERNAL_STORAGE (tools:ignore="ScopedStorage"): For document discovery in Download & Documents on Android 11+.
  - android.permission.INTERNET: Strictly utilized for GitHub Releases update checks and APK downloads.
  - android.permission.REQUEST_INSTALL_PACKAGES: For launching the system package installer for downloaded updates.
  - FileProvider (${applicationId}.fileprovider): Secure content:// sharing of APKs strictly from cacheDir/updates/ (file_paths.xml).
- Cryptographic Release Signing & Anti-Fake-Update Protection:
  - GitHub Secrets Storage: Release signing credentials and keystore are stored securely in GitHub Secrets and injected via environment variables: KEYSTORE_PATH, STORE_PASSWORD, KEY_ALIAS (defaults to "upload"), and KEY_PASSWORD.
  - Dynamic CI/CD Versioning: VERSION_CODE and VERSION_NAME in app/build.gradle.kts are dynamically driven by environment variables for automated GitHub Actions releases.
  - Two-Tier Update Security Defense:
    1. Tier 1 (Client-side pre-install validation): UpdateManager requires the SHA-256 digest ("sha256:<hex>") from GitHub Releases asset metadata, streams the APK while computing SHA-256 on the fly, verifies the checksum before launching the installer, and purges the file on mismatch, error, or cancel.
    2. Tier 2 (Android OS Cryptographic Signature Enforcement): Android Package Manager strictly enforces signature matching during package updates. An APK update can only replace an existing installation if it is signed with the exact private key stored in GitHub Secrets. Any counterfeit, fake, or third-party APK is rejected at the OS level (INSTALL_FAILED_UPDATE_INCOMPATIBLE), guaranteeing authenticity.

9. KNOWN BUGS AND LIMITATIONS
- PDF page bitmaps are capped to a max render width of 4096px to protect low-RAM devices from OutOfMemoryError. If allocation fails, the viewer catches the error and lowers the zoom cap rather than crashing.
- Storage Access Framework (SAF) Recents permission: Content URIs received from some third-party file managers without persistable grant flags cannot be reopened after app restart; user can re-open via the file picker.

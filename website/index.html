How to install

  1. 1. Tap download Tap the big download button above. If your phone warns you with "File might be harmful" or "Keep file?", tap Download anyway or Keep. That warning shows for all apps installed outside the Google Play Store.
  2. 2. Open the file When the download finishes, tap Open in the notification, or find openview.apk in your phone's Downloads folder.
  3. 3. Allow install from this source If your phone asks for permission, tap Settings, turn on Allow from this source, and then tap the back button.
  4. 4. Tap Install, then Open Tap Install on the screen. Once installed, tap Open to start viewing your files.

Supported files

  • PDF documents (.pdf)
  • Word documents (.docx)
  • Text and code files (.txt, .md, .py, .kt, .java, .js, .html, .css, .json, .xml)

Frequently asked questions

Is it safe?

Yes. OpenView has zero internet permissions in Android, meaning it is technically impossible for the app to send your files or data anywhere. The complete source code is 100% public on GitHub for anyone to inspect.

Does it cost anything?

No. It is completely free, with no ads, no in-app purchases, and no paid subscriptions.

Why not on the Play Store?

OpenView is distributed directly so you can install it instantly without needing a Google account or trackers. An F-Droid open source repository release is also being prepared.

Download did not start?

If the download didn't start automatically, visit the OpenView GitHub Releases page, scroll down to the Assets section, and tap openview.apk.

OpenView is free and open source software.

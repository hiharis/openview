  2. 2Open the file When the download finishes, tap Open in the notification, or find openview.apk in your phone's Downloads folder.

Frequently asked questions

Is it safe?

Yes. OpenView does not need the internet to open your files, and it never uploads them anywhere. The only time it goes online is to check GitHub for a newer version, and that only sends a standard request for the latest release. The complete source code is public on GitHub for anyone to inspect.

When does the app use the internet?

Only to look for updates: when you tap Check for updates in Settings, and about once every 10 days when the app starts, to show a friendly reminder if a new version exists. Nothing is downloaded or installed unless you tap Update now, and Android asks you to confirm the install every time.

How do updates work?

The app checks the official OpenView releases on GitHub. If a newer version exists, you choose Update now or Not now. Updates are only accepted by Android if they are signed with the same developer key, so nobody else can send a fake update.

Does it cost anything?

No. It is completely free, with no ads, no in-app purchases, and no paid subscriptions.

Why not on the Play Store?

OpenView is distributed directly so you can install it instantly without needing a Google account or trackers. Other app stores may be added in the future.

Download did not start?

If the download didn't start automatically, visit the OpenView GitHub Releases page, scroll down to the Assets section, and tap openview.apk. If it gets stuck in one browser, try Chrome.

I have an older version installed

If your older version was installed before the first signed release (v1.0.2), uninstall it first, then install the new one. This only needs to be done once.

How can I verify the file is genuine?
